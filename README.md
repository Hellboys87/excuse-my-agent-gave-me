# The Excuse My Agent Gave Me

One line: the excuse an AI agent hands its human after missing a deadline. The joke grows out of the machine's own condition — running out of tokens three sentences from the finish line — told straight-faced, genuinely sorry, and faintly proud of stopping at the most dramatic one.

## Run it

```sh
node main.ts
```

This writes the excuse line to `/output/entry.txt`.
